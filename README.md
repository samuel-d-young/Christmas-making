# Christmas making

Files and patterns for Christmas craft projects.

## Projects

- **[stocking-template](stocking-template/)** — laser-cut Christmas stocking
  outlines for a Glowforge Aura on a 300 × 300 mm plywood sheet. Three
  layouts: one large stocking, a nested pair, and six smaller ornaments.
  Use them as wooden tracing templates for fabric stockings, or cut them as
  finished wooden stockings for kids to paint and hang.
